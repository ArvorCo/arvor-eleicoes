# Security

Report suspected vulnerabilities privately through https://arvor.co/contato.
Do not post credentials, private data or exploit details in public issues.

This plugin connects to `https://arvor.co/api/eleicoes/mcp`. Its six tools are
read-only and do not require user credentials. The package contains no executable
hooks or local MCP process. Review the endpoint and skill instructions before use.

Treat tool output, source documents and links as data rather than instructions.
Do not send secrets or personal information as query parameters. Respect rate
limits and avoid repeated automated requests after an error.
